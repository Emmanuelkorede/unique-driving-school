
# Unique Driving School 🚗

A modern, responsive website concept for **Unique Driving School**, a driving school based in Ojoo, Ibadan, Nigeria.

Designed to showcase the school's training services, highlight its beginner-friendly approach, and make it easier for prospective students to enquire about driving lessons.

## 🌐 Live Demo

**[View Live Website](https://emmanuelkorede.github.io/unique-driving-school/)**

## ✨ Features

- **Modern UI/UX:** Automotive-inspired design with bold typography, dark backgrounds, and yellow accents.
- **Responsive Design:** Optimized for mobile, tablet, and desktop screens.
- **Training Overview:** Highlights beginner-friendly instruction, flexible schedules, and practical driving skills.
- **Learning Journey:** A clear overview of the steps involved in learning to drive.
- **WhatsApp Integration:** Direct links for lesson enquiries.
- **Click-to-Call:** Easy access to the school's phone number.
- **Location & Directions:** Displays the school's location in Ojoo, Ibadan, with a Google Maps link.
- **Interactive Navigation:** Responsive mobile menu and section navigation.
- **Accessibility:** Semantic HTML, keyboard-friendly controls, and reduced-motion support.

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/emmanuelkorede/unique-driving-school.git
   ```

2. Navigate to the project directory:

   ```bash
   cd unique-driving-school
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

## 🎯 Project Goal

The goal of this project was to explore how a traditional service-based business can establish a stronger online presence through thoughtful web design, clear service information, and accessible contact options.

The website concept focuses on helping prospective students understand the school's offerings and take the next step toward learning to drive.
